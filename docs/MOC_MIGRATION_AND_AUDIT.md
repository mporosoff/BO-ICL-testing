# Migration and discrepancy tracker

The starting repository was audited revision `c2bf9e8` with additional uncommitted local changes. Those changes were preserved and integrated. In particular, strict numeric parsing and CSV embedding-list parsing were already improved; they were not reverted. The extracted handoff and original notebooks remain input/reference material outside Git. Only selected exact procedure/seed/archive/schema fixtures and prompt evidence are included as implementation assets.

MoC presets and newly mapped generic campaigns use the validated `campaign_config` schema and `CampaignService`, shared by the main browser, focused MoC view, library, and CLI. `toolkit_bridge.py` and `toolkit_main.js` adapt this one ledger to the existing main toolkit; shared records are never copied into mutable legacy `LocalBOState`. Main/focused MoC navigation carries the campaign ID. The focused graph embeds `/campaign-graph?campaign=…`, which serves the existing main renderer rather than a second chart implementation.

The legacy runner remains accessible and its saved settings/history retain their original interpretation. A legacy GPR selection means text embeddings, never the new synthesis-parameter GP. Legacy retries=8 means eight total attempts; legacy iteration caps retain their documented observation-count meaning rather than becoming new-measurement budgets silently. Newly shared campaigns explicitly label new-measurement budgets, permit zero, and exclude initialization from that budget.

`campaign_plot.py` maps measured records into the original graph schema. Initialization occupies consecutive positions labeled i1, i2, i3, … in supplied order, with a shaded region and a divider before BO step 1. Each new physical measurement advances the subsequent BO step; refinements retain the original position. Drawing initialization in sequence does not make it BO-selected or charge it to the new-measurement budget. Pending predictions remain separate from the measured incumbent. Comparison overlays require matching pool and initialization fingerprints and objective/settings compatibility; one independent arm does not acquire a fabricated replicate-variation band. Shared sparse campaigns omit full-dataset statistics and hidden-label random expectations.

`campaign_controls.py` uses `CampaignService.create_control` for linked random arms. Their initial observations are cloned once from immutable initialization, never from later parent outcomes. Their results and reservations stay independent. Resuming returns the saved arm; starting a new control preserves the earlier history. A finite parent budget caps the control request. Exporting the parent exports that campaign; preserve each independent arm's archive when transferring a full comparison.

Generic imports require explicit independent feature mapping. Objective labels become measured initialization and are removed from candidates; absent labels remain unmeasured. Log transforms validate positive input, categorical encoding is one-hot, and scaling is fixed by full-space bounds. Generic structured noise uses reported uncertainty or an explicit configured fallback (default standard deviation 1 in objective units), with unknown metadata still recorded as missing. Generic settings do not apply MoC quality formulas or assume 0–100 bounds. The same shared lifecycle supports later engine changes, independent comparisons, controls, and portable export/import.

Generic `gap` inputs normalize to `closure_gap` without losing an explicit zero or its source; conflicting aliases fail validation. The generic unbounded LLM zero-baseline target scale defaults to 1 in objective units and is configurable in the main advanced controls, rather than inheriting MoC's 100-point range. Bounded objectives use their configured range.

The source RWM tuning rule is retained exactly: one burn-in adjustment multiplying the proposal step by `clip(burn_acceptance / 0.3, 0.3, 3)`. Sampler state and diagnostics are exported. Coverage uses distinct measured designs, clarifying how repeats differ from observation count. The default 1,000 burn-in plus 4,000 retained draws and thinning20 are retained, not replaced with NUTS, SAAS, MAP, or an embedding method.

Source chronology is unknown unless explicitly recorded. Source row order is preserved as source order. M24's 3.5-point accounting residual is incomplete phase accounting, not an invented graphite fraction or forced renormalization. The M12 zero-gap override and phase-sigma differences remain visible provenance.

The earlier `BO-ICL_Diagnosis_and_Fixes_*` and `BO-ICL_Report_v1.docx` files are historical audit artifacts. This migration note and the implementation report describe the delivered behavior.

Validation uses local numerical checks, mocked provider responses, saved-state/HTTP integration checks, and synthetic demonstrations. Provider credentials and external network access are excluded from the default suite. Live provider availability, paid requests, and new laboratory measurements remain unverified; the saved source observations are provenance, not evidence that a new experiment was performed.

The follow-up audit exposes manual inverse targets and standalone inverse proposal records in both views. The latter never enter the finite-pool reservation/measurement ledger. Full request previews use the same builder as execution and remain read-only; missing cached selector inputs and unknown future shortlist choices are explicitly unresolved. Managed system-message placeholders are identified as templates rather than full effective requests. Custom and recorded requests retain their own exact text.

Measurement quality now has versioned method, normalization, source/refinement identifiers and uncertainty provenance. The confirmed M7/M12/M13 values remain unchanged. Their historical quantification is explicitly unspecified; confirmation alone is not evidence of GSAS-II mass fractions or area-fraction equivalence. A documented definition decision either excludes unknown history from training or retains it with scientific justification. Explicit incompatible definitions cannot be silently mixed for training or comparison, and excluded measured records remain visible. This records scientific decisions without performing re-refinement or validating publication claims. The MoC engine retains the original six numerical synthesis transforms.
