810c3f7d7ecc632e4cfd422977b10b471e526f82, retained as provenance only. Their
chemistry statements are historical model instructions, not independently
validated claims. SHA-256 hashes are in manifest.json.

Operational template moc-corrected-v1 preserves phase identity, finite grid,
precursor mass ratios, and the detailed inverse fixed protocol. It removes
outcome leakage, achievement guarantees, and monotonic temperature claims;
uses one scalar objective on both sides of inverse examples; and explicitly
requests one retrieval query. Forward examples separate procedures from
historical phase response metadata. Candidate queries contain procedures only.

Historical automatic target: best + abs(best) _ Normal(1.2, 0.05).
Corrected target: best + direction _ max(0, draw - 1) \* abs(best), then physical
bounds (an explicit positive reference scale replaces abs(best) only at zero).
Historical agreement fallback: Gaussian standard deviation of observed labels.
Corrected agreement: an empirical point mass, with zero completion dispersion.
Historical n=5 inverse request discarded four completions. Corrected n=1 uses
and records its single completion. Forward n=5 preserves duplicate mass.

Custom system text is supplied verbatim and recorded as custom with a checksum;
no content-prefix heuristic regenerates it. Exact effective messages, model
parameters, raw completions, selected examples, retrieval ranks and random state
are recorded by the engine for replay.
